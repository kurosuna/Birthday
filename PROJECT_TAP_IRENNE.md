# Project TAP --- Irenne Birthday NFC 🎂

## Core Concept

Sebuah lanyard dengan NFC tersembunyi yang ketika di-tap membuka **mini
interactive birthday experience** untuk **Irenne**.

Experience terasa seperti menemukan easter egg rahasia: awalnya cute dan
innocent, lalu semakin absurd/chaotic, sebelum akhirnya berubah menjadi
personal dan wholesome.

> **North Star:**\
> "Apakah ini membuat Irenne merasa sedang menemukan sebuah tiny secret
> world yang dibuat khusus untuk dia?"

Kalau iya → masuk.\
Kalau cuma membuat website terlihat lebih sophisticated → tidak perlu.

------------------------------------------------------------------------

## Creative Direction

Visual mengambil inspirasi dari **kawaii Japanese mascot / Chiikawa-like
atmosphere**: warna pastel, bentuk bulat, ilustrasi sederhana, ekspresi
karakter yang lebay, sticker, speech bubble, dan humor absurd.

Bukan menyalin karakter Chiikawa secara langsung. Project menggunakan
**original tiny mascot universe** khusus untuk Irenne agar experience
memiliki identitas sendiri.

### Tone

**Cute → Funny → Chaotic → Unexpectedly Wholesome**

Website tidak boleh terasa seperti website ucapan ulang tahun biasa.
Experience harus lebih terasa seperti **mini episode interaktif** yang
secara tidak sengaja ditemukan melalui NFC.

------------------------------------------------------------------------

## Story Premise

Begitu NFC di-tap, user seolah memasuki dunia kecil yang mendeteksi
bahwa seseorang bernama **Irenne** baru saja muncul.

Mascot kecil bertugas memeriksa siapa yang datang.

``` text
...
eh?

someone tapped the thing.

IRENNE DETECTED
```

Kemudian dilakukan pemeriksaan yang terlihat sangat serius tetapi
sebenarnya bodoh.

``` text
Name: Irenne ✓
Human: probably ✓
Birthday girl: ✓
Getting older: ✓
Mentally prepared: ✕
```

Mascot mulai panik.

``` text
WAAAAAA—

⚠️ BIRTHDAY EVENT DETECTED
```

Kemudian seluruh dunia berubah menjadi birthday celebration.

------------------------------------------------------------------------

## The Mascot

Mascot menjadi **host / companion** sepanjang experience.

### Character Direction

Makhluk original yang:

-   kecil
-   putih
-   bulat
-   ekspresinya sederhana
-   agak bodoh
-   lovable
-   terlalu serius menjalankan birthday protocol

Contoh expression state:

``` text
( •ᴗ• )       normal
( •̀ᴗ•́ )و    determined
( º□º )       shocked
(╥﹏╥)         crying
٩(ˊᗜˋ*)و      celebrating
```

### Running Gag

Mascot terlalu serius menjalankan tugas yang sebenarnya sangat
sederhana.

Contoh:

``` text
Mascot is preparing something...
```

Beberapa detik kemudian:

``` text
Mascot forgot what it was doing.
```

# Experience Flow

## Chapter 01 --- Discovery

Halaman pertama sangat sederhana.

Background pastel. Mascot berdiri sendirian.

``` text
...

oh?

someone is here.
```

CTA:

**\[ poke \]**

Jangan langsung menyebut "Happy Birthday" agar surprise belum bocor.

------------------------------------------------------------------------

## Chapter 02 --- Irenne Inspection

Mascot mendekati layar dan melakukan scan.

### Identity Check

``` text
IDENTITY CHECK

Name ........ Irenne ✓
Birthday .... TODAY ✓
Age ......... classified 🔒
Cute ........ suspiciously high
Stability ... questionable
```

Kemudian:

``` text
WARNING

Irenne has gained another level.
```

Mascot shock.

------------------------------------------------------------------------

## Chapter 03 --- Emergency Birthday Protocol

Fake loading sequence:

``` text
Initiating birthday protocol...

█████████░ 93%
```

Loading berhenti.

Mascot:

``` text
...

why did it stop
```

User harus melakukan **poke**.

Loading menjadi:

``` text
██████████ 100%
```

Kemudian layar meledak dengan confetti.

# HAPPY BIRTHDAY IRENNE!! 🎂

Ini menjadi **first major payoff**.

------------------------------------------------------------------------

## Chapter 04 --- Irenne Patch Notes

Irenne diperlakukan seperti software yang baru mendapat major update.

### IRENNE vXX.0 --- RELEASE NOTES

``` text
✨ Level +1
🧠 Wisdom +0.7%
😴 Sleep resistance −12%
🍰 Cake compatibility +100%
💸 Financial decision module — still under investigation
🐣 Cuteness — developer refuses to nerf
```

### Known Issues

``` text
• Random mood changes
• Requires snacks periodically
• May become sleepy
• No fix planned
```

Footer:

``` text
Overall system status:
somehow operational ✓
```

Isi final harus dipersonalisasi berdasarkan sifat dan inside jokes
Irenne.

------------------------------------------------------------------------

## Chapter 05 --- Tiny Memories

Setelah chaos, mascot menemukan sebuah box.

``` text
I found these.
```

Masuk ke bagian photo / memory cards.

Foto muncul satu per satu seperti **polaroid / sticker**, bukan gallery
formal.

Contoh:

``` text
📷 [photo]

Irenne when behaving normally

(rare footage)
```

Swipe berikutnya:

``` text
📷 [photo]

Evidence #02
```

Mascot dapat muncul di sudut foto memberikan komentar kecil.

Target awal: **3--6 foto/memories**.

------------------------------------------------------------------------

## Chapter 06 --- Sudden Emotional Damage

Setelah beberapa foto, tone perlahan berubah menjadi lebih tenang.

Mascot:

``` text
...

okay.

I was told to give you something.
```

Muncul amplop:

💌 **\[ open \]**

Animasi menjadi lebih tenang. Background music juga dapat berubah.

Di sinilah masuk **personal birthday message**.

Pesan tidak perlu terlalu panjang. Karena mayoritas experience
sebelumnya bercanda, bagian serius yang singkat justru diharapkan terasa
lebih impactful.

------------------------------------------------------------------------

## Chapter 07 --- Mascot Cannot Handle Feelings

Setelah pesan selesai, mascot diam.

``` text
(╥﹏╥)

...

I'm not crying.

something entered my eye.
```

Tone kemudian kembali sedikit absurd agar ending tidak terlalu
melodramatis.

------------------------------------------------------------------------

# Final Scene

Mascot duduk sambil memegang kue kecil.

``` text
Anyway...

mission accomplished. 🎂

Happy Birthday, Irenne.

Please continue existing.
```

Di bawahnya:

``` text
Birthday Protocol: COMPLETE ✓
```

``` text

```

Setelah berkali-kali:

``` text

```

Bisa ditambahkan beberapa hidden reaction lain.

# Design Rules

## 1. Mobile First

Target utama adalah smartphone portrait karena entry point berasal dari
NFC.

Desktop compatibility tetap ada, tetapi bukan prioritas utama.

## 2. One Screen = One Moment

Jangan memberikan terlalu banyak informasi sekaligus.

Setiap tap / swipe / scroll harus membawa user menuju beat cerita
berikutnya.

## 3. Minimal UI

Hindari elemen website tradisional seperti:

-   navbar
-   hamburger menu
-   footer formal
-   menu navigasi
-   layout corporate

User harus merasa sedang menjalankan **experience**, bukan browsing
website.

## 4. Animation With Purpose

Animation digunakan untuk storytelling:

-   mascot movement
-   loading bar
-   speech bubble
-   confetti
-   photo swipe
-   reaction animation
-   envelope opening

Jangan membuat semua elemen bergerak sekaligus.

## 5. Short Text

Mayoritas dialog hanya sekitar **1--2 kalimat**.

Copywriting harus terasa seperti percakapan dengan mascot.

## 6. Cute Imperfection

Elemen visual boleh memiliki:

-   sedikit wobble
-   hand-drawn feeling
-   imperfect shapes
-   sticker rotation
-   playful spacing

Terlalu polished justru dapat menghilangkan charm.

## 7. Performance First

Karena website dibuka melalui NFC, waktu dari **tap → first screen**
harus terasa secepat mungkin.

Foto dan audio harus dioptimasi.

# Technical Foundation

## Architecture

``` text
[NFC Card]
     │
     │ NDEF URL
     ▼
[GitHub Pages]
     │
     ▼
index.html
style.css
app.js
     │
     ├── assets/
     │   ├── mascot/
     │   ├── photos/
     │   ├── audio/
     │   └── icons/
     │
     └── static experience
```

## Stack

-   GitHub Pages
-   HTML5
-   CSS
-   Vanilla JavaScript
-   Static assets
-   No backend
-   No database
-   No login
-   No framework required

NFC hanya menyimpan **NDEF URL** menuju GitHub Pages.

Dengan demikian, website dapat diperbarui kapan saja tanpa menulis ulang
NFC selama URL tidak berubah.

------------------------------------------------------------------------

# Audio

Background music bersifat optional.

Karena browser mobile umumnya membatasi autoplay, audio baru dimulai
setelah user melakukan interaction seperti menekan tombol **\[ poke \]**
atau **\[ open \]**.

Harus tersedia:

-   Play
-   Pause / Mute
-   Volume yang tidak mengagetkan

Audio tidak boleh menghambat experience jika gagal dimuat.

# Definition of Done

Project dianggap selesai ketika:

1.  Irenne dapat tap NFC tanpa instruksi teknis.
2.  Browser membuka experience dengan benar.
3.  First screen muncul dengan cepat.
4.  Surprise tidak langsung bocor dari landing page.
5.  Seluruh experience dapat diselesaikan hanya dengan tap/swipe
    sederhana.
6.  Birthday reveal terasa sebagai payoff.
7.  Funny/chaotic section tetap memiliki pacing.
8.  Personal message terasa berbeda dari bagian comedy.
9.  Final easter egg bekerja.
10. Experience dapat dibuka ulang dari NFC kapan pun selama GitHub Pages
    tetap aktif.
